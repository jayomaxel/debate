# P2-4 运维文档

## 本轮目标

为最终交付补齐部署、回滚、备份恢复和安全基线文档，降低交接和运维风险。

## 修改文件

- `ops/deploy.md`
- `ops/backup_restore.md`
- `ops/security_baseline.md`

## 代码逻辑

- `ops/deploy.md`
  - 说明开发和生产两套 compose 的启动方式。
  - 列出关键环境变量、持久化目录、健康检查和回滚步骤。
- `ops/backup_restore.md`
  - 明确 PostgreSQL、上传目录和 Redis AOF 的备份对象。
  - 给出逻辑备份、目录归档和恢复步骤。
- `ops/security_baseline.md`
  - 汇总工作包 C 的安全约束：
    - 会话与 ticket
    - 上传安全
    - 配置脱敏
    - 审计与限流
    - 网关暴露面
    - 发布前校验要求

## 对应功能

- 新人可以按文档完成部署和恢复演练。
- 安全与上线要求从聊天记录收束到仓库内文档。
- 后续收尾优化时，可以直接按文档核查环境变量、备份和安全基线。

## 风险/未完成项

- 文档提供的是最小可执行基线，正式生产环境仍需结合实际域名、监控平台和密钥托管方案细化。
- 若后续补充镜像仓库、自动发布或对象存储备份，需要同步更新这三份文档。
